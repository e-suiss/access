# Shadow agent discovery examples

Recorded and scrubbed answers of the services the discovery connectors read (AG-39, AG-43): the third-party applications people granted access in a connected service. Every identifier is synthetic. The connector tests parse each one and report the applications no registered agent or client of the realm accounts for.

- `google-workspace-tokens.json`: Admin SDK Directory API `users.tokens.list`.
- `microsoft-graph-grants.json`: Microsoft Graph `oauth2PermissionGrants`.
